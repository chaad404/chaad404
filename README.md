### 🛋️ The "Work-From-Home" Philosophy

- 🏠 **Engineering Mode:** 100% Cozy WFH advocate. My cleanest architectures and best debugging sessions happen in oversized hoodies with a giant mug of tea.
- 🤖 **Why AI & Agentic Systems?** Why spend 10 minutes doing something manually when you can spend 3 weeks orchestrating LangGraph multi-agent pipelines to automate it?
- 🔬 **The Serious Academic Deliverable:** Currently completing my BSc thesis at the **University of Pécs** *(Stipendium Hungaricum Scholar)*—engineering an automated **LLM Comparative Evaluation Framework** with RAG grounding and deterministic NLP metrics.
- ⚙️ **Backend Craft:** Building rock-solid APIs in Python, Java (Spring Boot), and PostgreSQL that run so stably that I can sleep uninterrupted.
- 🦊 **Where is all my code?** I lived peacefully on **[GitLab (@rokayaarakhi)](https://gitlab.com/rokayaarakhi)** for years. I am now gradually migrating active projects here so GitHub's empty contribution graph stops judging me.
- ☕ **Golden Rule:** *"It works on my machine"* is a valid architectural solution if we just containerize my machine with Docker.

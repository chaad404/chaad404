### 💫 About Me

I am a **Software Engineer** specializing in **AI/LLM Systems**, **Backend Engineering**, and **Distributed Architecture**. Currently completing my BSc in Computer Science / Software Engineering at the **University of Pécs**, Hungary *(Stipendium Hungaricum Scholar)*.

- 🔬 **Current Thesis & Research**: Designing a reproducible **LLM Comparative Evaluation Framework** featuring multi-agent orchestration (LangChain, LangGraph), RAG semantic grounding, and deterministic NLP scoring.
- 🤖 **Why Agentic AI?** Why spend 10 minutes doing something manually when you can spend 3 weeks orchestrating multi-agent pipelines to automate it completely?
- ⚙️ **Backend Craft**: Architecting robust RESTful microservices, clean database pipelines, and high-performance server architectures (Python, Java / Spring Boot, PostgreSQL, Docker) built to run so stably that nobody calls me on weekends.
- 🦊 **Where is all my code?** I lived peacefully on **[GitLab (@rokayaarakhi)](https://gitlab.com/rokayaarakhi)** for years. I am now gradually migrating active projects and tools here so GitHub's empty contribution graph stops judging me.
- ☕ **Golden Rule:** *"It works on my machine"* is a valid architectural solution if we just containerize my machine with Docker.

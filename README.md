### 👩‍💻 About Me

I am a **Software Engineer** specializing in **AI/LLM Systems**, **Backend Engineering**, and **Distributed Architecture**. Currently finishing my BSc in Computer Science / Software Engineering at the **University of Pécs**, Hungary *(Stipendium Hungaricum Scholar)*.

- 🔬 **Current Thesis & Research**: Designing a reproducible **LLM Comparative Evaluation Framework** with multi-agent orchestration (LangChain, LangGraph), RAG document grounding, and deterministic NLP quality metrics.
- ⚙️ **Core Focus**: Developing robust RESTful microservices, clean database pipelines, and high-performance server architectures (Python, Java / Spring Boot, Node.js).
- 🦊 **GitLab Transition**: All my prior engineering implementations, repositories, and internship tasks are hosted on **[GitLab (@rokayaarakhi)](https://gitlab.com/rokayaarakhi)**. I'm actively rolling out my open-source projects and tools here on GitHub.
